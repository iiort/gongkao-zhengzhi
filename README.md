# 政治理论 · 常识判断 体系化辨析题库

把桌面上的公考资料（《理论讲练》《排坑手册》《消化清单》）整理成**知识体系树 + 易混选择题**，
按 部分 → 篇 → 章 → 节 → 知识点 分类，做成了一个练习网页。

## 直接用

**双击打开 `政治理论挖空填词.html`** 即可（单文件，样式/脚本/题库全部内嵌，离线可用，
手机浏览器也能打开）。练习记录保存在本机浏览器（localStorage）。

也可以用 `web/index.html`（分文件版本，方便改样式或加题库）。

## 里面有什么

| 文件 | 说明 |
| --- | --- |
| `政治理论挖空填词.html` | **主交付物**：单文件练习网页 |
| `知识点总表.md` | 每个知识点的「体系树 + 题目（含答案与解析）」，可当背诵稿 |
| `web/` | 网页源码：`index.html` `style.css` `app.js` `data.js`（题库 JSON） |
| `text/` | 14 个 PDF 的原始文本抽取结果（按页分隔） |
| `sections/` | 按知识点切分后的教材原文（156 个小节） |
| `facts3/` | 每个小节的「体系树 + 题目」JSON（中间产物） |
| `tools/` | 生成脚本：抽文本 → 切章节 → 合并题库 → 打包单文件 → 导出总表 |

## 题库是怎么做的

1. **体系树**：每节先梳理成 2~4 层结构，例如
   `科学体系 → 主要内容 → 十个明确 / 十四个坚持 / 十三个方面成就 / 六个必须坚持`，
   「十个明确」下面把十条全部列出，「六个必须坚持」每条都标注地位（根本价值立场、内在精神特质…）。
   网页里点「**体系图**」就能看到这棵树的完整展开，当前题目所在节点会高亮。
2. **易混选项**：四个选项刻意做成同一范畴、同一层级、同一句式，只差一点：
   - 张冠李戴：把「十个明确」的内容说成「十四个坚持」的；
   - 移花接木：「最本质的特征 / 最大优势 / 根本保证 / 显著标志」互换；
   - 换限定词：「决定性作用 ↔ 基础性作用」、「主体地位 ↔ 主导地位」、「根本 ↔ 基本」；
   - 改数字 / 年份 / 届次 / 会议名；
   - 同框架内其他条目冒充正确项。
3. **每道题都有解析**，直接点出「错项错在哪」，并标注它在体系里的位置。
4. **选项位置统一打乱**（`merge3.py`，固定随机种子，可复现）：原始生成结果里正确答案严重偏向 A，
   打乱后四个位置各占约 1/4；解析里「A项 / B项」的指代会同步重映射，
   `维生素A、D、E、K`、`B族`、`A型` 这类非选项的字母会被保护、不参与重映射。

## 网页功能

- **四选一**：点选项或按 `1–4`，答错立即标红并给出正确项。
- **体系图（整页视图）**：点卡片右上角「体系图」或解析里的「看体系图 ›」，进入整页的框架视图——
  顶部是**结构概览**（分块索引，点一下跳转），下面按「一、二、」「（一）（二）」的纲目体分层，
  条目自动编号，当前题目所在的节点会高亮并自动定位。
  左上角「← 返回题目」、右下角常驻悬浮按钮都能一键回到题目；`Esc` 也一样。
- **间隔重复（SRS）**：每道题是一张卡片，答对升级、间隔拉长（10 分钟 → 1 天 → 2 天 → 4 天 →
  7 天 → 15 天 → 30 天 → 60 天），答错清零、8 分钟后重新出现。
- **今日任务**：先清到期题，再学新题；新学额度可调（10/20/30/50/80/120 题/天）。
- **错题当轮回炉**：答错的题隔 3 道后会再问一次。
- **章节树**：五级，显示 `已学/总数`；节点后的「练」按钮可单练一节。
- **错题 / 收藏 / 搜索**：搜索可一键只练命中的题。
- 键盘：`1–4` 作答、`Enter` 下一题、`←/→` 翻页、`Esc` 退出体系图。
- 夜间模式、手机端抽屉式侧栏、进度全部存本地浏览器。

### 建议的用法

1. 每天打开只点**「开始今日复习」**，做完就关——让算法决定复习谁。
2. 政治理论是重点：把每日额度调到 50，集中把第一部分滚一遍；常识判断可以慢慢来。
3. 答错别急着跳过，先看解析里那句话「错项错在哪」，这是这类题最容易混的点。
4. 想快速过一遍框架时，直接点「体系图」看树，不答题也能看。

## 视觉

方向是「深墨书桌 + 纸面书页」：左侧一整块深墨色，右边是纸面上一张浮起的白卡。

- **对比**：侧栏 `#0D1115` 的深墨与纸面 `#F2EFE8` 形成硬分割，侧栏右侧一条极细的朱红渐变收边。
- **层次**：卡片圆角 14px，两层阴影（1px 贴边 + 28px 扩散），纸上浮起；选项是 10px 圆角的小卡，
  悬停上浮 1px。深色模式下同一套层级降明度。
- **记忆点**：卡片左上角悬挂一个大号衬线题号（`01`、`02`…），朱红 24% 透明度，像书的章序号。
- **用色**：朱红 `#B22C22` 只做三件事——主操作、答错、当前状态；松绿 `#1E6E5B` 只表示答对；金色只给收藏与连续天数。
- **字体**：题干宋体 25px／1.85，选项宋体 16px，界面黑体；数字用衬线，读出「本子」的味道。
- **编号**：体系图用「一、」「（一）」「1.」的纲目体，与卡片上的阿拉伯题号区分开——一个表层级，一个表顺序。
- 纸面叠了一层极淡的噪点（SVG turbulence，3.5%），深色模式去掉；`prefers-reduced-motion` 下关闭所有过渡。

## 专题·十五五规划（2026—2030）

侧栏最上面单独一块，18 节、250 道题，全部来自官方原文，不是二手解读：

- 底本一：[《中共中央关于制定国民经济和社会发展第十五个五年规划的建议》](https://www.gov.cn/zhengce/202510/content_7046050.htm)（2025 年 10 月 23 日二十届四中全会通过）
- 底本二：[《中华人民共和国国民经济和社会发展第十五个五年规划纲要》](https://www.gwytb.gov.cn/topone/202603/t20260314_12755559.htm)（2026 年 3 月全国人大批准）

18 节：发展环境与历史方位 / 指导方针与六条原则 / 主要目标与关键指标 / 现代化产业体系 / 科技自立自强 /
数字中国与人工智能 / 强大国内市场 / 高水平社会主义市场经济体制 / 高水平对外开放 / 农业农村现代化 /
区域协调与新型城镇化 / 文化强国 / 人口高质量发展 / 民生与共同富裕 / 绿色转型与美丽中国 /
国家安全与平安中国 / 国防军队与“一国两制” / 民主法治与规划实施

题目专打时政最爱考的地方：**数字、提法、归属**。比如「研发经费年均增长 7% 以上」用「7% 左右 / 5% 以上 / 8% 以上」做干扰，
「劳动年龄人口平均受教育年限 11.7 年」用「十四五」已达的 11.3 年做干扰。
所有含数字的正确答案都用脚本核对过一遍，54 个数字全部能在原文里找到（`tools/verify_topic.py`）。

## 重建

```powershell
$py = "C:\Users\admin\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py tools\extract_pdf.py      # PDF -> text/
& $py tools\split_sections.py   # text -> sections/
& $py tools\split_topic.py      # 纲要全文 -> sections_topic/（18 节）
& $py tools\merge3.py           # sections + sections_topic + facts + facts_topic -> web/data.js
& $py tools\build_single.py     # web -> 政治理论挖空填词.html
& $py tools\export_md.py        # web/data.js -> 知识点总表.md
```
